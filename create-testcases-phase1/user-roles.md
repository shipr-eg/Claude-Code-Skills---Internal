# EG Ajour – User Roles & Actions by Module
 
This document maps user roles to their typical actions within each Ajour module.
Use this as a reference when writing story descriptions ("As a [user type]...") and
when validating that acceptance criteria target the correct actor.
 
---
 
## User Roles
 
| Role | Description |
|---|---|
| Building Owner | Primarily a viewer and receiver of information |
| Adviser / Architect / Engineer (structural and MEP) | Creates, follows up, and responds across modules |
| General / Turnkey Contractor | Creates, responds, and manages across modules |
| Main Contractor | Creates, responds, and manages across modules |
| Sub-contractor | Primarily responds and contributes within assigned scope |
 
---
 
## Inspect & QA
 
| Action | Roles |
|---|---|
| Viewing registrations, sometimes commenting | Building Owner |
| Creating and following up on supervision and defect registrations | Adviser, Architect, Engineer |
| Responding, creating, and following up on defects | General / Turnkey Contractor, Main Contractor |
| Responding to defects | Sub-contractor |
| Responding to Technical Queries (TQ) | Adviser, Architect, Engineer |
| TQ and QC documentation | General / Turnkey Contractor, Main Contractor |
| Creating TQ and QC documentation | Sub-contractor |
| Creating snag / punch list during handover | Adviser, Architect, Engineer |
| Contributing to snag / punch list before handover | General / Turnkey Contractor, Main Contractor |
 
---
 
## Ajour Box
 
| Action | Roles |
|---|---|
| Viewing and downloading project material, meeting notes, contracts | Building Owner, Adviser, Architect, Engineer, General / Turnkey Contractor, Main Contractor, Sub-contractor |
| Uploading nothing | Building Owner |
| Uploading drawings, descriptions, meeting notes, project specifications | Adviser, Architect, Engineer |
| Uploading meeting notes, contracts, as-built material, change orders | General / Turnkey Contractor, Main Contractor |
| Uploading as-built material, change orders | Sub-contractor |
| Setting up and administering folders and folder access | Adviser, Architect, Engineer, General / Turnkey Contractor, Main Contractor |
| Collaborating on project material, meeting notes, contracts | General / Turnkey Contractor |
 
---
 
## Facility Management (FM)
 
| Action | Roles |
|---|---|
| Receiving documentation | Building Owner |
| Administering the platform, ensuring all contractors deliver their information | Adviser, Architect, Engineer, General / Turnkey Contractor, Main Contractor |
| Contributing / documenting information about constructed building parts | General / Turnkey Contractor, Main Contractor, Sub-contractor |
 
---
 
## Tender
 
| Action | Roles |
|---|---|
| Administering the tender | Building Owner, Adviser, Architect, Engineer, General / Turnkey Contractor, Main Contractor |
| Attending as bidder | Adviser, Architect, Engineer, General / Turnkey Contractor, Main Contractor, Sub-contractor |
 
---
 
## Mobile Ajour App
 
| Action | Roles |
|---|---|
| Viewing registrations in Inspect / QA (rarely) | Building Owner |
| Viewing drawings from Box (rarely) | Building Owner |
| Viewing drawings from Box | Adviser, Architect, Engineer, General / Turnkey Contractor, Main Contractor, Sub-contractor |
| Creating and following up on registrations in Inspect / QA | Adviser, Architect, Engineer, General / Turnkey Contractor, Main Contractor, Sub-contractor |
