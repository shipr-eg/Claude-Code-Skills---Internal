# Security Vulnerability Fix Workflow
1. Read the JIRA ticket using MCP JIRA tools
2. Analyze the vulnerability and affected dependencies
3. Create a fix branch (ASK user for approval first)
4. Implement the upgrade and run tests
5. Create PR with description
6. Update JIRA ticket with fix details
7. Create/update Confluence documentation
8. Generate release notes
9. Save context file for future sessions

IMPORTANT: Ask for explicit approval before any git write operation.
